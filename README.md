# Number Guessing Game 🎯

## Description

This is a simple Java Number Guessing Game.
The program generates a random number between 1 and 100, and the player has to guess the correct number.

The game provides hints:

* "Too High" if the guessed number is greater than the random number.
* "Too Low" if the guessed number is smaller than the random number.
* "Correct!" when the player guesses the right number.

---


## How to Run

### Step 1: Compile the Program

javac Numbergame.java


### Step 2: Run the Program

java Numbergame
