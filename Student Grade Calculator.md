## 🎓 Student Grade Calculator

A simple Java console-based application that calculates total marks, average percentage, and assigns a grade based on the marks entered by the user.

---

## 📌 Project Title
**Student Grade Calculator (Java Console Application)**

---

## 📖 Description
This project takes marks of 5 subjects as input from the user, calculates the total and average, and then assigns a grade based on the average score.

It helps to understand basic Java concepts like:
- Scanner class for input
- Conditional statements (if-else)
- Arithmetic operations
- Data types

---

## ⚙️ Features
- Input marks for 5 subjects
- Calculates total marks
- Calculates average percentage
- Assigns grade based on performance:
  - A (90 and above)
  - B (80–89)
  - C (70–79)
  - D (60–69)
  - F (below 60)

---

## ▶️ How to Run

javac StudentGradeCalculator.java
java StudentGradeCalculator
